# Приватность

Egoist Shield хранит состояние приложения и журналы локально на устройстве. Диагностический архив скрывает известные форматы токенов, subscription URLs и персональные сетевые данные.

Сетевые обращения выполняются только для явно используемой функции: API подписки, публичные проверки IP/DNS/скорости, официальные upstream/release endpoints и выбранные пользователем сетевые targets. Отправка HWID провайдеру подписки выключена по умолчанию и управляется отдельной настройкой.

Публичный репозиторий не принимает diagnostics с персональными данными. Перед прикреплением файла проверьте его содержимое вручную.
