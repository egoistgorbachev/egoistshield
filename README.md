# EgoistShield

EgoistShield is a Windows network quality assistant for personal desktop environments.

The public repository is intentionally release-focused. It provides verified installer
downloads, update metadata, checksums, and user-facing release notes without publishing
internal implementation details.

## Download

Use the latest GitHub Release:

https://github.com/egoistgorbachev/egoistshield/releases/latest

Each release includes:

- Windows installer
- incremental update metadata for desktop updates
- SHA-256 checksum for integrity verification

## Product Scope

EgoistShield focuses on:

- network diagnostics
- DNS profile management
- startup and background service reliability
- connectivity stability checks
- clean install and update flow
- compact desktop UX for everyday network maintenance

EgoistShield is not presented as a tool for accessing restricted resources or avoiding
network rules. Use the application only in accordance with applicable law and the rules
of your network environment.

## Update Channel

Desktop builds check GitHub Releases for new versions. The latest release is the source
of truth for installer assets and checksums.

## Support

For support, use the Issues section of this repository and include:

- app version
- Windows version
- what action was attempted
- visible error text
- relevant diagnostic output with personal data removed
