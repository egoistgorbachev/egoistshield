# Решение проблем

## Обновление не найдено

Проверьте доступ к `api.github.com` и `github.com`. Ошибка DNS, proxy, TLS, timeout или HTTP 404 показывается как отдельный сбой и не означает, что версия актуальна.

## SmartScreen предупреждает о файле

3.5.0 пока не имеет Authenticode. Скачивайте Setup только из официального release, сверяйте `.sha256` и manifest. Не отключайте Defender или Smart App Control ради установки на устройстве, где политика запрещает неподписанный EXE.

## Установка не завершена

Setup хранит журнал в `%ProgramData%\EgoistShield\Installer\Logs`. При ошибке transactional upgrade возвращает предыдущую версию и её прежние owned-службы. Не удаляйте quarantine вручную: повторный Setup сначала выполняет безопасный Recover.

## Интернет после изменения не работает

Откройте «Главная» → «Восстановить интернет». Операция возвращает owned state Egoist Shield и сохраняет здоровый внешний DNS/прокси. Экспортируйте диагностику, если проверка readback не прошла.
